# Bread
Hello! The easiest programming language in the world... Introducing Bread. Built on top of Python, all you need to do to run this language is download Bread.exe.
File extensions for this language:
.br (Main Code File): BRead
• Purpose: The primary source file that contains all the main program code we write, including commands enclosed in curly braces.
.bros (Save and Data File): Bread Readable Object Storage
• Purpose: Similar to JSON, this is a data file used to permanently store user assets, wallet balances, or program settings on the computer.
.bruh (Error and Log File): Bread Runtime Unexpected Halt log
• Purpose: An official report file that records errors—essentially capturing a "bruh moment" for the system—whenever invalid data is entered or an error occurs during code execution.
